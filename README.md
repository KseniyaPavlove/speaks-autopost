# Агент автопубликации S.peaks

Агент сам выкладывает готовый контент из Figma в Instagram, Telegram, VK, YouTube Shorts и TikTok
по расписанию из Google-таблицы и переписывает подпись под каждую площадку в голосе S.peaks.

```
Google-таблица (очередь)  ──►  агент (GitHub Actions, каждые 15 мин)  ──►  Instagram / Telegram / VK / Shorts / TikTok
Figma (макеты) ─────────────┘        │  Claude адаптирует тексты               │
Google Drive (видео Reels) ─┘        └──►  админ-чат Telegram: превью, отчёты, ошибки
```

**Как работает:**
1. SMM-специалист добавляет строку в таблицу: дата, время, формат, ссылка на фрейм Figma (или видео), текст для Instagram.
   Ставит статус **«готово»**.
2. За 12 часов до выхода агент присылает в админ-чат **превью**: картинку и тексты для каждой площадки.
   Если что-то не нравится, впишите свой вариант в колонку `текст_tg` / `текст_vk` / … — агент возьмёт его.
3. В назначенное время агент выгружает JPG из Figma, скачивает видео и публикует.
   В чат приходит отчёт со ссылками. Если площадка выдала ошибку, агент повторяет ещё 2 раза и сообщает.
4. Всё, что опубликовано, записывается в `state/published.json`, поэтому дублей не бывает.

## Таблица-очередь

Шаблон: `templates/queue_template.csv` (Google Таблицы → Файл → Импорт).

| Колонка | Что писать |
|---|---|
| `id` | короткое уникальное имя: `reels-understand`. Не меняйте после публикации |
| `дата`, `время` | `21.10.2026`, `18:30` (московское время) |
| `формат` | `пост`, `карусель`, `reels`, `сторис` |
| `площадки` | `все` или через запятую: `ig, tg, vk, yt, tt` |
| `figma` | ссылка на фрейм (ПКМ по фрейму → Copy link). Для карусели: ссылки на слайды через пробел **или** одна ссылка на секцию — слайды берутся слева направо |
| `видео` | для reels: ссылка на файл в Google Drive (доступ «все, у кого есть ссылка») |
| `текст` | подпись для Instagram — из неё агент делает остальные |
| `текст_tg`, `текст_vk`, `текст_tt`, `заголовок_yt`, `текст_yt` | необязательно: свой текст для площадки вместо сгенерированного |
| `статус` | `готово` — публиковать; всё остальное (`черновик`, пусто) агент пропускает |

Что куда уходит:

| Формат | Instagram | Telegram | VK | YouTube Shorts | TikTok |
|---|---|---|---|---|---|
| пост / карусель | ✅ (до 10 слайдов) | ✅ альбом | ✅ | — | — |
| reels | ✅ | ✅ (до 50 МБ) | ✅ видео | ✅ | ✅ |
| сторис | ✅ | — | — | — | — |

Если пост «проспал» больше 6 часов (например, статус поставили поздно), агент его не публикует, а пишет в чат.

## Настройка (один раз, ~1–2 часа)

Все ключи кладутся в репозиторий: **Settings → Secrets and variables → Actions**.
Секреты (`secrets`) скрыты, переменные (`variables`) видны — в таблицах ниже указано, куда что.

### 1. Репозиторий на GitHub
Создайте репозиторий и загрузите в него эту папку.
- **Публичный** репозиторий — Actions бесплатно без лимита; ключи всё равно хранятся скрыто в Secrets.
- **Приватный** — бесплатно 2000 минут/мес. Тогда в `.github/workflows/autopost.yml` замените `*/15` на `*/30`.

### 2. Google-таблица
Импортируйте шаблон, затем **Настройки доступа → Все, у кого есть ссылка → Читатель**.

| Имя | Куда | Значение |
|---|---|---|
| `QUEUE_URL` | secret | ссылка на таблицу (лист с очередью) |

### 3. Figma
Figma → Settings → Security → **Personal access tokens** → права *File content: read*.
У токена есть срок действия — поставьте напоминание, чтобы продлить.

| `FIGMA_TOKEN` | secret | токен |
|---|---|---|
| `FIGMA_SCALE` | variable | необязательно: `2`, если фреймы нарисованы в 540 px вместо 1080 |

### 4. Telegram (канал + админ-чат)
1. @BotFather → `/newbot` → получите токен.
2. Добавьте бота **администратором канала** с правом публикации.
3. Админ-чат: создайте группу с командой SMM и добавьте туда бота. ID группы можно узнать через @getmyid_bot (вида `-100…`).

| `TG_BOT_TOKEN` | secret | токен бота |
|---|---|---|
| `TG_CHANNEL` | variable | `@speaks_channel` или `-100…` |
| `ADMIN_CHAT_ID` | variable | ID админ-чата |
| `CONTACT_TG` | variable | контакт для призывов в TG, например `@speaks_manager` |
| `CONTACT_SITE` | variable | сайт для описаний YouTube |

### 5. Instagram
Нужен **профессиональный аккаунт**, привязанный к **странице Facebook**.
1. developers.facebook.com → Create App → тип *Business* → добавьте продукт **Instagram** (API с Facebook Login).
2. Ваш аккаунт Facebook должен быть админом приложения — тогда проверка Meta не нужна.
3. На компьютере: `pip install requests` и `python tools/get_tokens.py instagram` — скрипт подскажет шаги и выдаст:

| `IG_USER_ID` | variable | ID Instagram-аккаунта |
|---|---|---|
| `IG_ACCESS_TOKEN` | secret | бессрочный ключ страницы |

Лимит Instagram: 100 публикаций через API в сутки.

### 6. VK
Публиковать фото и видео на стену можно только ключом **пользователя-администратора** (ключ сообщества для этого не подходит).
1. id.vk.com → «Мои приложения» → новое Web-приложение, укажите доверенный Redirect URL (например, страницу вашего сайта).
2. `python tools/get_tokens.py vk` — войдите аккаунтом админа сообщества.

| `VK_GROUP_ID` | variable | ID сообщества (число, без минуса) |
|---|---|---|
| `VK_ID_CLIENT_ID` | variable | ID приложения |
| `VK_DEVICE_ID` | secret | из скрипта |
| `VK_REFRESH_TOKEN` | secret | из скрипта |

VK ID выдаёт новый refresh-ключ при каждом обновлении, и агент сохраняет его сам. Для этого нужен `GH_PAT` (шаг 9).
Если у вас уже есть бессрочный ключ пользователя с правами `wall, photos, video, groups, offline`, можно задать только `VK_ACCESS_TOKEN`.

### 7. YouTube Shorts
1. console.cloud.google.com → новый проект → включите **YouTube Data API v3**.
2. OAuth consent screen: тип External, затем **Publish app → In production**. В режиме Testing ключ перестаёт работать через 7 дней.
3. Credentials → OAuth client ID → тип **Desktop app**.
4. `python tools/get_tokens.py youtube` — войдите аккаунтом канала.

| `YT_CLIENT_ID`, `YT_CLIENT_SECRET`, `YT_REFRESH_TOKEN` | secret | из скрипта |
|---|---|---|

Видео, загруженные через непроверенный проект Google, YouTube может ставить в «Доступ ограничен».
Агент это заметит и напишет в чат — тогда откройте видео вручную или пройдите проверку проекта (YouTube API Services Audit).

### 8. TikTok
1. developers.tiktok.com → приложение с продуктами **Login Kit** и **Content Posting API** (включите *Direct Post*), права `video.publish`, `video.upload`.
2. `python tools/get_tokens.py tiktok`.

| `TT_CLIENT_KEY`, `TT_CLIENT_SECRET`, `TT_REFRESH_TOKEN` | secret | из скрипта |
|---|---|---|

⚠️ Пока приложение не прошло **аудит TikTok**, видео публикуются только как «видно мне». Агент об этом предупредит.
Через API публикуются только видео, карусели в TikTok не уходят.
Учтите также, что TikTok ограничивает загрузку контента для аккаунтов, зарегистрированных в России.

### 9. Обновление ключей — GH_PAT
Нужен, чтобы агент сохранял обновлённые ключи TikTok и VK ID.
GitHub → Settings → Developer settings → **Fine-grained tokens** → только этот репозиторий → право **Secrets: Read and write**.

| `GH_PAT` | secret | токен |
|---|---|---|

### 10. Claude (адаптация текстов)
console.anthropic.com → API Keys. Без ключа агент тоже работает: тогда он адаптирует тексты по простым правилам
(меняет «директ» на нужный контакт, чистит хэштеги, собирает заголовок для Shorts).

| `ANTHROPIC_API_KEY` | secret | ключ |
|---|---|---|
| `CLAUDE_MODEL` | variable | необязательно, по умолчанию `claude-sonnet-5-5` |

Правила голоса бренда лежат в **`brand.md`**. Правьте их там, и агент сразу начнёт писать по-новому.

### 11. Проверка
GitHub → **Actions → «Автопостинг S.peaks» → Run workflow**:
- `check` — проверит таблицу, Figma и каждую площадку и пришлёт отчёт в админ-чат;
- `dry-run` — покажет, что и с какими текстами опубликовал бы прямо сейчас, ничего не публикуя;
- `run` — обычный запуск (то же самое агент делает сам каждые 15 минут).

Первую публикацию лучше сделать тестовой: строка с ближайшим временем и `площадки: tg`.

## Полезные настройки (variables)

| Имя | По умолчанию | Что делает |
|---|---|---|
| `PREVIEW_HOURS` | 12 | за сколько часов присылать превью (0 — не присылать) |
| `YT_PRIVACY` | public | `unlisted`/`private` для тестов |
| `TT_PRIVACY` | PUBLIC_TO_EVERYONE | приватность в TikTok |

## Локальный запуск
```
pip install -r requirements.txt pytest
python -m agent list --source templates/queue_template.csv     # как агент понял таблицу
python -m agent run --dry-run --source templates/queue_template.csv --now 2026-10-21T18:40
python -m pytest -q tests
```

## Ограничения
- GitHub запускает расписание с задержкой до ~15 минут, поэтому пост выходит в интервале «время из таблицы + 0–20 минут».
- Если в репозитории 60 дней нет активности, GitHub отключает расписание. Агент сам коммитит журнал после публикаций, так что при регулярном постинге это не грозит.
- Сторис публикуются только в Instagram, без стикеров и ссылок: API их не поддерживает.
- Через Telegram-бота нельзя загрузить видео больше 50 МБ.
